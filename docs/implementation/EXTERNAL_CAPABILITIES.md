# External capabilities та credential matrix

Дата review офіційних джерел: 2026-07-31.

## Статус репозиторію

У поточному source немає provider SDK/client, OAuth callback, webhook receiver, RTMP/WebRTC session, payment/email/model/push adapter або server-side secret boundary. UI-згадки провайдерів не є інтеграціями. Жодна зовнішня capability не пройшла production verification.

Усі рядки матриці мають однакові mandatory gates:

1. **Current provider review** — повторно прочитати офіційні docs, terms, changelog і regional restrictions перед реалізацією та перед launch.
2. **Credentials** — отримати окремі test і production credentials, зберігати server-side у secret manager, визначити rotation/revocation.
3. **Approval/scopes** — отримати app review, account eligibility, scopes, contracts або feature enablement, які реально вимагає provider.
4. **Quota** — виміряти надані limits, погодити capacity, backoff, degradation і increase process.
5. **Verification** — contract tests у test environment і controlled live test із реальним provider response, webhook/event signature та operational telemetry.

Без цих п’яти gates production verification неможлива. Наявність документації доводить лише documented capability, а не право конкретного SYLORA account її використовувати.

## Мінімальний provider acceptance record

Для кожної обраної integration зберігається dated record:

- official docs/changelog/terms URLs і reviewed versions;
- approved use case та explicitly unsupported cases;
- owner, provider account, test/prod project IDs без secret values;
- credentials location, scope, creation/rotation/revocation dates;
- approved scopes/features, reviewer evidence й account eligibility;
- observed quotas та capacity assumptions;
- webhook/event signature scheme, retry/order/idempotency behavior;
- data categories, regions, retention, subprocessors і deletion path;
- sandbox contract-test result;
- controlled production smoke-test result;
- degradation, disable switch, incident contact і exit plan.

До появи такого record UI не повинен показувати integration як connected, operational або production-ready.
