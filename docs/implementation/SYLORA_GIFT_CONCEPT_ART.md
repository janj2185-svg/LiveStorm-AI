# SYLORA Gift Concept Art

Concept visualizations for original SYLORA gifts (not TikTok clones).  
These are **mood / poster references** for artists — not runtime GLB assets and **not READY** catalog gifts.

**Folder:** `artifacts/sylora-gift-concepts/`  
**Also:** `/opt/cursor/artifacts/sylora-gift-concepts/`

**Coverage:** Wave 1 + Wave 2 = **48 posters**. All **Rare (1–20)** and **Epic (21–40)** templates have art; Wave 1 also includes selected Legendary / Mythic / Divine signatures.
