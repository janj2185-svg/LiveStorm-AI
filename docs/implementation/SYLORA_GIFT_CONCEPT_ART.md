# SYLORA Gift Concept Art

Concept visualizations for original SYLORA gifts (not TikTok clones).  
These are **mood / poster references** for artists — not runtime GLB/WAV assets and **not READY** catalog gifts.

**Folder:** `artifacts/sylora-gift-concepts/`  
**Also:** `/opt/cursor/artifacts/sylora-gift-concepts/`

**Coverage:** Waves 1–3 = **100 posters**, covering all 100 SYLORA gift templates from `SYLORA_GIFT_100_ORIGINALS.md`.

| Wave | Range | Count |
|---|---|---:|
| Wave 1 | gift-01 … gift-20 | 20 |
| Wave 2 | gift-21 … gift-48 | 28 |
| Wave 3 | gift-49 … gift-100 | 52 |
| **Total** | | **100** |

Filenames use kebab-case after `gift-NN-` (e.g. `gift-49-cohost-overture-suite.png`, `gift-92-oracle-honest-status.png`, `gift-94-garden-unsent-lines.png`, `gift-97-cathedral-soft-power.png`).
