# Ethereal v2 — Motion specification (draft)

## Laws
1. Energy, not spin — Sigil lives via breath, shimmer, particles.
2. Glass settles — surfaces fade/rise; no bounce gimmicks.
3. Aura appears on intent — never ambient cover.
4. Reduced motion — opacity/crossfade only; no orbits.
5. One hero motion per viewport.

## Durations
| Token | ms | Use |
|---|---|---|
| `fast` | 120–160 | hover/press |
| `med` | 280–360 | sheet/panel |
| `slow` | 600–800 | scene enter |
| `sigil` | 4200–6800 loop | idle brand |
